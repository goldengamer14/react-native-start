# Project documentation

This directory documents the subscription-tracking mobile application in this
repository. It excludes the separate `example/` tree.

For a concise setup guide and project summary, start with the root
[README](../README.md).

## Documents

- [Product overview](./product-overview.md) — confirmed product goal, current
  scope, and implementation status.
- [Architecture](./architecture.md) — source layout, navigation, shared code,
  configuration, and assets.
- [Screens and features](./screens-and-features.md) — route inventory and
  what each screen currently does.
- [Data and design](./data-and-design.md) — domain types, sample data, theme,
  fonts, and imagery.
- [Development](./development.md) — setup, run commands, configuration, and
  validation notes.

## Keeping these docs current

Describe behavior that exists in the code as **Implemented**. Label the
confirmed product goal separately from implemented functionality, and mark
unfinished or absent behavior as **Not implemented** rather than implying it
already works. Update the relevant page when its source, routes, configuration,
or visible behavior changes. Keep implementation details in code and link to
them here instead of duplicating large blocks.
